“Interesado en Diseño de Sistemas de Información Comprensibles (DSIC)”

Organización, estructuración y traducción de información compleja —contenidos jurídicos— en sistemas visuales y funcionales coherentes, priorizando la usabilidad, la eficiencia cognitiva y la equidad en el acceso, mediante la aplicación de principios de diseño de información, sistemas de diseño escalables y claridad jurídica.

Jerarquización y visualización de datos complejos (tablas, diagramas, flujos), reducción de carga cognitiva, narrativa visual.

Creación de componentes reutilizables, estandarización de interacciones, mantenimiento de consistencia visual y técnica en productos digitales.

Simplificación de documentos normativos (contratos, políticas, términos), uso de lenguaje claro, incorporación de elementos visuales y flujos empáticos para usuarios no expertos.

Competencias transversales:

Pensamiento sistémico: entender cómo las partes (componentes, cláusulas, datos) se relacionan en un todo funcional.

Diseño centrado en la persona: adaptar la complejidad a las necesidades y capacidades del usuario final.

Prototipado y pruebas de usabilidad: validar tanto interfaces como documentos legales.

Documentación y gobernanza: crear guías, estándares y reglas de evolución para el sistema (sea de diseño, de información o legal).
