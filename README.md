“Interesado en Diseño de Sistemas de Información Comprensibles (DSIC)”: que organiza, estructura y traduce información compleja —ya sea datos, interfaces digitales o contenidos legales— en sistemas visuales y funcionales coherentes, priorizando la usabilidad, la eficiencia cognitiva y la equidad en el acceso, mediante la aplicación de principios de diseño de información, sistemas de diseño escalables y claridad jurídica.

Competencias transversales:
Pensamiento sistémico: entender cómo las partes (componentes, cláusulas, datos) se relacionan en un todo funcional.

Diseño centrado en la persona: adaptar la complejidad a las necesidades y capacidades del usuario final.

Prototipado y pruebas de usabilidad: validar tanto interfaces como documentos legales.

Documentación y gobernanza: crear guías, estándares y reglas de evolución para el sistema (sea de diseño, de información o legal).
